# Sentiment Analysis & Word Cloud Generation

## Project Overview
This project demonstrates sentiment analysis and word cloud generation using Python. It uses a sample dataset of customer reviews to identify positive, negative, and neutral sentiments and visualise frequently occurring words in negative feedback.

## Problem Statement
Analyse a collection of customer reviews to understand customer sentiment and identify commonly occurring words in negative feedback using Python.

## Dataset
The dataset contains 22 sample customer reviews covering product quality, product performance, and customer service.

**Dataset file:** `Sentiment_Analysis.csv`

## Tools & Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- TextBlob
- WordCloud

## Project Workflow

1. Imported the required Python libraries.
2. Loaded the customer review dataset using Pandas.
3. Performed sentiment analysis using TextBlob.
4. Classified reviews into Positive, Negative, and Neutral categories based on sentiment polarity.
5. Analysed the distribution of sentiment categories.
6. Filtered negative customer reviews.
7. Combined negative reviews into a single text string.
8. Generated a Word Cloud to visualise frequently occurring words in negative feedback.

## Key Concepts Demonstrated
- Data loading and processing
- Natural Language Processing (NLP) fundamentals
- Sentiment analysis
- Text filtering and manipulation
- Data visualisation
- Word Cloud generation
